How the environment works, watch this [lecture](https://www.youtube.com/watch?v=eP8EsoNwUqU).

```bash

conda activate ydata_profiling
pip install ydata-profiling
pip install pipreqs
pip install streamlit
```

## 4. convert the app into windowed application

To convert the Streamlit app into a windowed application, you can use a tool like `pyinstaller`.

1. First, install `pyinstaller` if you haven't already:

```bash
pip install pyinstaller
```
2. Next, create a spec file for your Streamlit app. You can do this by running:

```bash
pyinstaller --name=DataProfilingApp --onefile --windowed app.py
# or
pyinstaller --name=DataProfilingApp --onefile --windowed --collect-all streamlit --collect-all ydata_profiling --hidden-import=pandas --hidden-import=numpy --hidden-import=seaborn app.py
```

3. After running the above command, a `dist` folder will be created in your current directory. Inside this folder, you will find the executable file named `DataProfilingApp` (or `DataProfilingApp.exe` on Windows).
4. You can now run this executable file to launch your Streamlit app as a windowed application.
5. Note that you may need to include additional files or dependencies depending on your app's requirements. You can customize the spec file generated by PyInstaller to include these as needed.
6. For more advanced usage and options, refer to the [PyInstaller documentation](https://pyinstaller.readthedocs.io/en/stable/).
7. Keep in mind that packaging Streamlit apps can sometimes be complex due to their web-based nature, so ensure to test the executable thoroughly to confirm all functionalities work as expected.
8. If you encounter any issues, consider checking online forums or the Streamlit community for additional support.
9. Enjoy your windowed Data Profiling App!

## 6. Why PyInstaller is not recommended for Streamlit Apps
> Key Reasons to Avoid PyInstaller with Streamlit
### 1. Architectural Mismatch
Streamlit is fundamentally a web server application that runs on localhost and requires a browser
PyInstaller is designed for standalone desktop applications, not web servers
This creates an inherent incompatibility in how the application is meant to run
### 2. Complex Dependency Management
Streamlit has numerous dynamic imports and runtime dependencies
PyInstaller struggles to detect all these dependencies automatically
You need extensive --hidden-import and --collect-all flags (as shown in your readme)
Missing even one dependency can cause silent failures
### 3. Large Executable Size
Bundling Streamlit and all its dependencies (pandas, numpy, web server components, etc.) results in extremely large executable files (often 200-500 MB+)
This makes distribution impractical
### 4. Port and Browser Issues
The packaged app needs to:
Start a web server on a specific port
Launch a browser to connect to that port
Handle port conflicts if already in use
These operations are unreliable in a frozen executable environment
### 5. Static Asset Problems
Streamlit uses static files (CSS, JS, images) that must be correctly bundled
File paths break when frozen, causing UI elements to fail or look broken
### 6. Poor User Experience
Users see a command window or terminal flash
Browser window opens separately (feels disjointed)
Error messages are hidden or difficult to debug
Updates require redistributing the entire large executable
### 7. Maintenance Nightmare
Each Streamlit version update may break your PyInstaller build
Requires constant testing and spec file adjustments
Community support is limited since this isn't the intended use case
### Better Alternatives (as your readme suggests)
✅ Tkinter/PyQt wrapper (like your app_tkinter.py) - launches Streamlit in a subprocess
✅ Docker containers - for consistent deployment
✅ Streamlit Cloud - for web deployment
✅ Electron wrapper - for true desktop app feel

## 7. Alternative Method

If the app does not work as exe file try to use Tkinter or PyQt to create a GUI that launches the Streamlit app in a web browser.

We have a app_tkinter.py file that uses Tkinter to create a simple GUI for launching the Streamlit app. You can find it [here](./app_tkinter.py).
